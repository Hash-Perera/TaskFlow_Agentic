# TASK-004 — Integrated Review

## Goal

Perform an independent review of the integrated TaskFlow CRUD implementation.

## Owner

Reviewer Agent

## Mode

Read-only unless explicitly instructed otherwise.

## Review Sources

Read:

* `AGENTS.md`
* `docs/requirements.md`
* `docs/acceptance-criteria.md`
* `docs/api-contract.md`
* `docs/architecture.md`

Review the integrated backend, frontend, and tests.

## Review Areas

Evaluate:

1. correctness
2. API contract compliance
3. architecture compliance
4. validation
5. MongoDB/Mongoose usage
6. frontend/backend integration
7. error handling
8. security
9. maintainability
10. unnecessary complexity
11. test quality
12. scope violations

## Severity

Classify findings as:

* Critical
* High
* Medium
* Low

## Finding Format

For every actionable finding provide:

* severity
* file
* relevant code
* reason
* impact
* recommended fix

Do not invent findings just to produce a longer report.

## Restriction

Do not modify code during the review task.

Implementation fixes must be assigned separately after human approval.
